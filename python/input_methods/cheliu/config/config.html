蝦米擴充功能說明

v/r/s/f 快速選字
候選字視窗開啟時，v、r、s、f 分別對應候選字清單裡的第 2、3、4、5 個字。
按下去會把這個字母併入組字區（例如打 ix 出現候選字「我／曳」後按 v，組字區會顯示「ＩＸＶ」），候選字清單也會窄化成只剩選到的那一個字。
跟輸入其它任何字一樣，還是要按空白鍵或 Enter 才會真正上字，不會一按 v/r/s/f 就自動送出；如果按錯想重來，按退格會完整還原回選字前的狀態。
體感上就像字碼表裡真的有「ixv → 曳」這筆字碼，但實際上字碼表完全沒有改動。

反查拼音（按「` h」查字/查詞）
忘記某個字的蝦米字碼時，可以暫時切換成拼音輸入來查詢：

1. 組字區是空的狀態下按「`」，再按 h（h 代表「漢語」拼音，固定用這個按鍵序列進入；不管接下來拼音開頭是哪個字母都一樣，包含 m/u/e/h 本身——那三個字母單獨接在「`」後面仍然是既有的多功能前導字元功能，分別對應設定選單／Unicode 輸入／emoji 選單，不受影響）。
2. 打漢語拼音（含聲調數字，例如 ni3），可以連續打多個音節組成詞（例如 fang3fu2 會自動修正成「彷彿」）。
3. 按方向鍵 ↓ 展開候選字清單，每個候選字後面會標注它在蝦米字碼表裡最短的字碼；按方向鍵 ←/→ 可以移動游標回頭修正不是最後一個字的地方（如果該位置剛好有收錄替代詞彙的話）。
4. 候選字清單展開後，上下左右鍵都可以移動清單裡的選字游標(不用再只靠數字鍵選字)，移到這一頁最前/最後一個字時會自動換頁，換到最後一頁之後再往後移會繞回第一頁。按 Enter 確定選取游標所在的候選字。
5. 候選字清單開啟時按 Esc 只會先關閉清單、不會離開反查拼音狀態，跟真正的新酷音操作一致；清單已經關閉時再按一次 Esc 才會真正離開反查拼音模式。
6. 候選字清單關閉的狀態下按 Enter 確定送出，並且會列出剛剛送出的字（或詞）裡每一個字的完整蝦米碼，這個提示訊息會持續顯示，直到您按下任意一個鍵才會消失。


如果自動選字選錯的是比較前面的字、而且當下的游標位置又沒有收錄替代詞彙（游標移過去按 ↓ 候選字沒有變化），可以退格刪掉後面已經打好的字，剩下想修正的那個字時按 ↓ 選好之後，再重新打一次後面的音節接上去即可。
底層是內嵌一份獨立的 libchewing 引擎來查詢拼音候選字，跟系統裡有沒有安裝「新酷音」這個輸入法無關。

拆錯字碼自動清除
打一串查無此字的字碼（例如 LLLL）按空白鍵後，畫面上的錯誤字碼會直接清空，不用再手動按退格——這是啟用了「拆錯字碼時自動清除輸入字串」這個設定（打字行為功能頁面裡可以關閉）。

使用說明

關於 PIME

PIME 輸入法平台網站：PIME 輸入法平台
PIME 輸入法平台版本：


PIME 是在 Windows上使用 Python 3 開發 TSF 中文輸入法的平台，由作者 洪任諭(PCMan) 所開發，目前支援到 Windows 10，並且能支援 Windows app container (Metro mode)。可以讓開發者在不了解系統細節的情況下，單純使用 Python 就能實作支援 Windows 的輸入法模組。

蝦米是在 PIME 輸入法平台下，基於 CIN 碼表所實現的蝦米輸入法模組。本身移植了 PIME 平台下新酷音大部份的功能，並參考了微軟輸入法的一些操作方式，讓使用者轉移過來使用時，能夠馬上就上手，而不須要重新去適應。
